# Impulse 26 Design Festival

Landing page for **Impulse 26**, SAP's design festival at SAP Labs Montreal (October 1st, 2026).

## How to open

Double-click `index.html`. There is no build step and no dependencies beyond the Inter font from Google Fonts.

## Deploy

The site is static and deployed on Vercel, which serves `index.html` at `/`.

## Files

```
index.html                 # all markup, styles, and the countdown script
images/SAP-impulse.svg     # hero logo mark
images/icons/              # section icons (location, time, calendar, question, group)
images/speakers/           # speaker photos and the hero group photo (people.png)
images/zhanara.webp        # speaker photo
images/who made it/        # organizing team photos
```
